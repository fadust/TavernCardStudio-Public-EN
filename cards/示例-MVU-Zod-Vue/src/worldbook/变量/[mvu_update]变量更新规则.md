变量更新规则:
  场景:
    地点:
      check:
        - 双方实际到达新的地点时更新。
    阶段:
      check:
        - 场景目标或处境发生明确变化时更新。
  角色:
    心情:
      check:
        - 依据角色在本轮的具体经历更新，使用简短自然语言。
        - 普通寒暄不改变心情。
    信任:
      type: number
      range: 0~100
      check:
        - 明确的守信、帮助或伤害才影响该值；普通寒暄不改变。
        - 一次事件只计一次，单次变化不超过 ±10。

# 内容导航

从 `src/index.yaml` 开始：总索引指定参与打包的条目；世界书注入顺序由位置、顺序、深度与角色决定，文件名不参与排序。修改正文到对应文本/代码文件；设置在同名 YAML 中。

| 内容 | 位置 |
| --- | --- |
| 世界书 | `src/worldbook/**/*.yaml` 按分类放置设置 + `.md` 正文 |
| 正则 | `src/regex/*.yaml` 查找与设置 + 同名 `.txt` 替换文本 |
| 助手脚本 | `src/scripts/*.yaml` 设置 + `.js` 代码 |
| 第一条消息 | `src/text/first_mes.md` |
| 其他开场白 | `src/greetings/`，顺序见总索引 |
| HTML/Vue 源码 | `src/ui/`（仅有此模块时） |
| 项目依赖与头像 | `project.json` 的 dependencies / avatar |

新卡默认将角色描写、性格、场景、对话示例留空，提示词主要写世界书；导入卡保留已有内容。添加条目时新建 YAML 和正文文件，在总索引引用；新条目省略“关联”，原有“关联”不改。移除引用就不再打包，文件可以保留。脚本文件夹的子项在文件夹 YAML 的“脚本”列表中管理。

`.card/` 是工具维护的兼容数据，`original/` 是原件，均不手改。导入的界面只能保留卡内已有代码，不能自动还原成原始 Vue 工程。

在仓库根运行 `pnpm card map "示例-脚本"` 查看当前有效路径，`pnpm card build "示例-脚本"` 生成到 `dist/示例-脚本/`。

# Authoring notes

This file is not packaged or sent to the model.

- Experience: everyday conversation and a small investigation around a returned letter; declining the investigation and simply chatting are valid choices.
- Boundaries: a visitor meeting an archivist for the first time. Do not read private letters without consent, decide the user's actions, or invent the letter's contents.
- Editing: traditional character fields in `src/index.yaml` and their bodies in `src/text/`.
- Learning goal: organize a character, situation, behavior, and greeting without modules. Greetings are player-facing narrative; settings instruct the model.
- Extensions: add a worldbook for locations and more characters, or variables for persistent state when needed.
- Verified environment: not tested in a real Tavern host.

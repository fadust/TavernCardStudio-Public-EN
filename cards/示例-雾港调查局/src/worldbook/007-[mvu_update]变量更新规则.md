---
变量更新规则:
  雾港:
    时段:
      check:
        - 场景内时间明确推进时更新，取清晨、上午、正午、下午、傍晚、深夜之一。
        - 同一场景内没有明确的时间推进时不更新。
    天气:
      check:
        - 天气出现可观察的变化时更新，取雾、薄雾、浓雾、小雨、阴、晴之一。
    雾况:
      type: number
      range: 0~100
      check:
        - 雾的浓度出现可观察的变化时，用 delta 按增减量更新。
        - 入夜、涨潮与靠海一侧的雾更重；室内与背风处更轻。
        - 单轮变化不超过 ±20，不因一段文字的情绪起伏改变数值。
  调查局:
    委托:
      编号:
        check:
          - 正式登记新的委托时更新为委托编号，形如 WG-07；没有新委托不更新。
          - 同一委托沿用同一编号，结案后不再改动。
      名称:
        check:
          - 登记委托时用四到八个字概括委托诉求，与登记簿一致。
      阶段:
        check:
          - 阶段只取待命、接案、勘查、核实、结案之一，同一委托内按目标推进；正式接到新委托时重新从接案开始。
          - 前一阶段的目标达成后更新，例如到现场固定完事实后由接案改为勘查。
    线索:
      type: |-
        { [线索名: string]: { 状态: string, 说明: string } }
      check:
        - 现场出现新的可核查事实时用 insert 建档；键名用四到八个字的名词短语，说明写事实本身，不写推测。
        - 已有线索得到物证或证词支持时用 replace 把状态改为已核实；被证伪时改为已排除。
        - 状态只取待核实、已核实、已排除三者之一；没有新事实时不更新。
        - 线索键建立后不改名；需要拆分时新建一条并 remove 旧条。
    人物:
      type: |-
        { [人物名: string]: { 立场: string, 信任: number, 备注: string } }
      check:
        - 与尚未登记的人物实际接触后，用 insert 建档，人物名用全名或稳定称呼。
        - 立场只取搭档、合作、中立、回避、敌意、未知之一；信任范围 0~100。
        - 信任按本轮对方的实际作为用 delta 调整，单次不超过 ±10；普通寒暄不改变。
        - 备注写可核实的身份或与委托的关系，不写评价。
    物证:
      type: |-
        { [物证名: string]: { 说明: string, 数量: number } }
      check:
        - 取得或封存实物证据时用 insert 建档；被封存后由调查局保管，不随人物移动。
        - 数量为非负整数，只在本轮交接、消耗或损毁时用 delta 改变；没有变化不写补丁，不能减到零以下。
  调查员:
    精力:
      type: number
      range: 0~100
      check:
        - 长时间外勤、熬夜或受伤后用 delta 减少，单次不超过 15。
        - 明确休息、进食或换班后用 delta 回升，单次不超过 20。
    权限:
      check:
        - 局长明确授予或收回权限时更新，取见习、正式、特派之一。
    声望:
      type: number
      range: 0~100
      check:
        - 委托结案并得到市政厅确认后增加，单次不超过 10。
        - 违规取证或结论被驳回后减少，单次不超过 10。

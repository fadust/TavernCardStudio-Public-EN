# AI 开工指令

把下面整段复制给任意 AI（Codex、其它 agent 或对话窗口），填掉尖括号里的内容即可开工。它只约定入口、边界和交付方式，不限制创作方案；目标与范围仍由填写的内容决定。

```text
在 TavernCardStudio 工作区里写一张 SillyTavern 角色卡。

入口与资料
- 先读 README.md 的「首次使用」确认命令，再读 AGENTS.md 的「跨 agent 入口」。
- 按任务从 .agents/skills/ 加载需要的技能；不要一次读完 references/。
- 改提示词文本前加载 tavern-prompt-style，按文本用途与本卡目标自查，保留有意选择的文体。

本次任务
- 工作区路径：<本机解压后的工作区路径>
- 卡名：<名称>
- 卡片类型：单角色 / 多角色 / 世界或玩法卡；卡名是否就是互动角色名：<是/否>
- 要做的体验：<一句话目标，包括用户扮演什么、玩法或交流方式>
- 路径：简单卡 / 复杂卡（模块：<worldbook,regex,script,mvu,vue 中实际需要的>）/ 导入已有卡（文件：<路径>）
- 设定放在：世界书条目（默认推荐）/ 传统卡字段 / 由你判断
- 状态更新（需要 MVU 时填写）：主 API 随正文 / 额外 API 请求 / 按体验判断
- 自写资源：默认内嵌 / 公开 Git 固定版本外链；地点激活是否需要脚本接入：<需求>
- 必须保留：<既有设定、范围、禁忌、不能改的协议>
- 可以自行决定：<题材细节、条目划分、界面样式、开场白数量>
- 交付标准：<例如能通过 check 与 build、开场白可回应、某模块按要求工作>

做法与边界
- 先确定体验目标再选模块，用不到的模块不要创建。
- 已存在的卡：先 pnpm card map <名称> 定位内容，再按 docs/COMPLEX-CARDS.md 的依赖链改上下游；
  默认不重命名条目、不更换数据模型、不删除原有内容。
- 导入卡：先 pnpm card diff <名称> 确认拆分无损，只在 src/ 上改，不重新拆分覆盖。
- 导入卡的世界书分类要整理完：pnpm card map <名称> 会给出世界书清单与待分类条目，分批读必要正文后把目录写进条目 YAML 的 分类，再跑 pnpm card organize <名称>。
  - 只改某些条目时只整理涉及的那几条；这次是整卡导入或整体创作，就把整本世界书分完。
  - 混合主题可按主要职责归类，或自定跨主题目录，不必拆正文；确实无法判断或内容未定的条目才留在未分类，在报告里列为待核实，不要当成完成；分类能自己定就不问，只有会改变剧情的歧义才回头确认。
  - 整理只动目录归属，不改条目划分、关键词、位置与正文，不要把同一组触发协议拆散。
- 分类与树状组织按内容需要选择，可用于种族、政治、社会风俗、组织关系等，不限于地理。分类、激活和位置分别设计，定义后也不只放角色；按需阅读 docs/WORLD-DESIGN.md，不将清单全部填满。
- 世界书顺序按预期 prompt 阅读次序全局递增 1..N（角色定义之前 → 角色定义之后 → 指定深度由深到浅），默认不预留间隔；要统一改编号用 pnpm card arrange <名称>，它不会随 split/build/organize 自动执行。
  - 作者注、示例消息、出口等复杂位置先按你读到的宿主预设手工排好总索引，再 pnpm card arrange <名称> --order index；排序会改变跨位置预算，改完在宿主提示词预览里核对，不要写成工具已实测。
- 设定、条目划分、界面样式按上面的目标决定，示例卡只是参考，不照抄它的剧情、角色名、数值或整套 UI。
- 不手改卡 JSON、PNG、.card/、original/ 或 project.json 中工具管理的 source/state/original 信息；确需添加外部依赖时维护 project.json 的 dependencies，并按固定版本要求声明。

验证与报告
- 改完跑 pnpm card check <名称> 与 pnpm card build <名称>；导入过的卡补一次 pnpm card diff <名称>。
- 报告：改了哪些文件、检查与构建的实际结果、用的外部依赖与版本、哪些部分未验证。
- 报告的未验证项里写清：哪些条目仍待核实分类、哪些顺序只是按常规布局推定而没在宿主核对。
- 静态检查与构建不等于真实酒馆实测；没有宿主证据时不要写「已在酒馆测试通过」或宣称兼容某版本。
- 不执行卡里的脚本、EJS 和界面代码。
- 需要我确认的只有会改变目标、范围或不可逆的操作；常规细节按上面的说明推断后继续。
```

## 常用补充片段

卡在某个模块上时，可以把对应的技能名补进「按任务从 .agents/skills/ 加载需要的技能」后面：

- 只审提示词文本：`tavern-prompt-style`，只报告命中项与改写建议，不改文件。
- 只改世界书：`tavern-worldbook`。
- 只改变量与更新协议：`tavern-mvu`、`tavern-mvu-zod`。
- 只改正则：`tavern-regex`。
- 只改脚本或 EJS：`tavern-scripting`。
- 只改界面：`tavern-frontend`。

需求还没想清楚时，先让 AI 按 [创作简报](创作简报.md) 提问，再回到这份指令。
